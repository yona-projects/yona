## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-44**: 게시글 "수정" 시 알림이 전혀 발송되지 않던 문제 수정. yona `BoardApp.editPost`의 `isSelectedToSendNotificationMail() || !original.isAuthoredBy(currentUser)` 조건(본인 글이 아니면 옵션과 무관하게 항상 발송, 본인 글이면 체크박스 선택 시에만 발송)을 그대로 이식.
  - `PostingService.updatePosting()`에 `sendNotificationMail: Boolean = false` 파라미터 추가. 기존에 있었지만 실제로는 한 번도 쓰이지 않던 `authorId` 파라미터를 "수정자(updater)"로 실사용해 `posting.authorId == authorId` 비교에 사용. 저장 전 원본 body를 보존해두고, 저장 후 조건을 만족하면 `EventType.POSTING_BODY_CHANGED` `NotificationEvent`를 발행(oldValue=원본 본문, newValue=수정된 본문), `WatchService.findActualWatchers`로 수신자 계산 — 기존 `createPosting`/`deletePosting`의 `publishNotification` 헬퍼와 다른 형태(oldValue가 필요해 재사용하지 못함)라 별도로 인라인 구현.
  - `BoardController.kt`(REST `PUT /api/projects/{id}/posts/{postId}`)의 `UpdatePostingRequest`에 `sendNotificationMail: Boolean?` 필드 추가, 서비스 호출에 전달.
  - **범위 확장 발견**: `BoardViewController.editPost()`(서버 렌더링 폼 제출 경로, `POST /{owner}/{projectName}/post/{number}/edit`)가 `PostingServiceImpl.updatePosting()`을 아예 거치지 않고 `postingRepository.save()`로 직접 저장하고 있어, 이 경로로 수정하면 옵션과 무관하게 알림이 100% 발송 안 되는 상태였음(레포지토리 직접 접근이라 서비스 계층의 어떤 알림 로직도 탈 수 없었음). `editPost()`를 서비스 호출로 리팩터링해 로직 중복 제거와 함께 해결 — 기존 동작(README 커밋 시 `posting.readme` 값을 유지하는 기존 방식, git 커밋에 쓰이는 title/body)은 그대로 보존.
  - `board/edit.html`: 실제 라이브 UI가 사용하는 AJAX 제출 경로(`PUT /api/projects/{id}/posts/{postId}`)에 "수정 알림 메일 발송" 체크박스를 추가 — yona와 동일하게 본인 글이고 README가 아닐 때만(`post.authorId == currentUser.id && !post.readme`) 노출되고 기본 체크됨. 체크박스가 없는 경우(본인 아닌 글) `sendNotificationMail: false`를 보내지만, 서버 로직이 본인 아닌 글은 이 값과 무관하게 항상 발송하므로 문제없음.
  - 테스트: `PostingServiceSpec.kt` +3 tests(본인 글+옵션 미선택 시 미발송/본인 글+옵션 선택 시 발송/타인 글은 옵션 무관 항상 발송), `BoardControllerSpec.kt` +1 test(REST 요청의 sendNotificationMail이 서비스로 전달됨), `BoardViewControllerSpec.kt` +2 tests(폼 제출 시 옵션 전달, 옵션 미선택 시 false 전달). 인접 회귀: `domain/board/*`, `web/Board*`, `YonaApplicationTests` 전체 재실행 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `./gradlew test --tests "com.github.yonaprojects.yona.domain.board.*" --tests "com.github.yonaprojects.yona.web.Board*" --tests "com.github.yonaprojects.yona.YonaApplicationTests"` 모두 통과.
