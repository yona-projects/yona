- **2026-09-07 추가 발견/수정(이 티켓과 별개 결함, 관련 있어 여기 기록)**: SVN Deploy Key
  지원 버그(`SvnAuthorizationFilter`가 `DeployKeyAuthenticationToken`을 인식 못해 항상 403)를
  고치던 중, 그보다 훨씬 심각한 결함을 발견했다 — **Spring Security 기본
  `StrictHttpFirewall`이 SVN이 실제로 쓰는 WebDAV 메서드(`PROPFIND` 등)를 허용 목록에서
  빠뜨려, 요청이 `SvnAuthorizationFilter`/`SvnController`에 도달하기도 전에 400으로 거부되고
  있었다.** 실제 `svn checkout`/`update`/`info`/`log`는 전부 `PROPFIND`를 쓰므로, 이 방화벽
  기본값 아래에서는 SVN-over-HTTP 자체가 완전히 동작 불가능한 상태였다. 기존 SVN 테스트가 전부
  `standaloneSetup()`이거나 `springSecurityFilterChain`을 안 태워서 이 문제를 한 번도 잡아낸
  적이 없었다(`DeployKeySvnAuthorizationIntegrationSpec`을 실제 보안 필터 체인을 태워서 작성
  하다가 발견). `config/SecurityConfig.kt`에 WebDAV/DeltaV 메서드를 허용하는 `HttpFirewall`
  빈을 추가해 해결. 전체 스위트(6176개) 재검증 GREEN.
