## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-45**: `GitAuthorizationFilter`가 `SvnAuthorizationFilter`([[tickets/p1-23|P1-23]]에서 이미 수정됨)와 완전히 동일한 두 가지 권한 축소를 그대로 갖고 있던 문제 수정. yona의 git 스마트 HTTP 경로도 SVN과 동일하게 `AccessControl.isAllowed`(project.isPublic() && !user.isGuest 규칙)에 의존한다는 전제 하에, SVN 필터에 적용한 것과 동일한 두 수정을 그대로 포팅.
  - `requiresAuth` 조건을 `project.projectScope == PRIVATE`(PROTECTED를 누락시킴)에서 `project.projectScope != PUBLIC`으로 변경 — PROTECTED 프로젝트도 이제 PRIVATE와 동일하게 인증 없이 clone 불가능해짐.
  - PUBLIC 분기(else)에 `UserRepository`를 신규 주입해 `!user.isGuest` 검사를 추가 — 게스트 계정으로 인증된 요청은 PUBLIC 프로젝트라도 403으로 거부.
  - 테스트: `GitAuthorizationFilterSpec.kt` +5 tests(PROTECTED 익명 401/PROTECTED 비멤버 403/PROTECTED 멤버 통과/PUBLIC+게스트 403/PUBLIC+비게스트 통과) — `SvnAuthorizationFilterSpec.kt`의 대응 케이스를 그대로 미러링. 인접 회귀: `config/git/*`, `config/svn/*`, `YonaApplicationTests`(신규 `UserRepository` 의존성 배선 확인) 전체 재실행 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `./gradlew test --tests "com.github.yonaprojects.yona.config.git.*" --tests "com.github.yonaprojects.yona.config.svn.*" --tests "com.github.yonaprojects.yona.YonaApplicationTests"` 모두 통과.
