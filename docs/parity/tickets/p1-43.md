## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-43**: 커밋 diff 화면/PR 화면 전용 멘션 후보 엔드포인트(`mentionListAtCommitDiff`/`mentionListAtPullRequest`)가 아예 없던 문제 수정. yona `ProjectApp.java`의 두 액션과 그 하위 헬퍼(`addCommitAuthor`/`addCodeCommenters`/`addCommentAuthors`)를 이식.
  - `GET /api/{owner}/{projectName}/mentionListAtCommitDiff`(commitId, pullRequestId?=-1) 신규 추가 — `pullRequestId`가 있으면 그 PR의 `fromProject`를 커밋 조회 대상으로 삼고(포크된 저장소의 커밋도 멘션 가능), `collectCommitAuthor`(커밋 작성자를 이메일로 조회 + email prefix를 loginId로 보는 폴백 검색)와 `collectCodeCommenters`(PR에 속하지 않은 해당 커밋의 코드 댓글 작성자, 최근 순)를 후보에 포함.
  - `GET /api/{owner}/{projectName}/mentionListAtPullRequest`(pullRequestId, commitId?) 신규 추가 — `collectCommentAuthors`(PR의 코드리뷰 댓글 작성자, 최근 순)와 PR `contributor`를 후보에 포함, `commitId`가 함께 오면 그 커밋 작성자도 추가.
  - `collectCodeCommenters`는 yona처럼 프로젝트 VCS가 SVN이면 `CommitComment`, 아니면(GIT) `CommentThread`+`ReviewComment`(PR에 속하지 않은 스레드만, `findByProjectAndCommitIdAndPullRequestIsNullOrderByCreatedDateDesc`)에서 작성자를 모으는 동일한 분기를 그대로 포팅 — yona의 기존 `ReviewViewController.newCommitComment`가 이미 이 정확한 GIT/SVN 분기로 두 저장 경로를 나눠 쓰고 있어([[tickets/p1-20|P1-20]]/기존 구현) 그 구조에 맞춰 조회 로직도 대칭으로 맞췄다.
  - 코드 중복 제거를 위해 기존 `buildUserMentionList`의 "후보→JSON 맵 변환" 부분을 `toMentionMaps()` 공용 헬퍼로 분리해 세 엔드포인트가 함께 사용.
  - **근사치로 남긴 부분**: 여러 스레드에 걸친 댓글의 전역 시간순 정렬은 정확한 단일 SQL 정렬 대신 "스레드를 최근 순으로 순회 + 스레드 내부는 오래된 순" 근사로 구현(정확한 크로스-스레드 시간순 정렬을 위해서는 새 커스텀 쿼리가 필요해 과설계로 판단) — 실사용상 한 커밋/PR에 여러 스레드가 짧은 시간差로 섞이는 경우가 드물어 결과 품질에 미치는 영향은 미미하다고 판단.
  - 테스트: `MentionControllerSpec.kt` +3 tests(커밋 작성자+코드댓글 작성자 포함, PR 리뷰 댓글 작성자+contributor 포함, 존재하지 않는 PR 404). 인접 회귀: `web/MentionControllerSpec`, `web/PullRequest*`, `web/Review*`, `domain/pullrequest/*`, `YonaApplicationTests` 전체 재실행 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `./gradlew test --tests "com.github.yonaprojects.yona.web.MentionControllerSpec" --tests "com.github.yonaprojects.yona.web.PullRequest*" --tests "com.github.yonaprojects.yona.web.Review*" --tests "com.github.yonaprojects.yona.domain.pullrequest.*" --tests "com.github.yonaprojects.yona.YonaApplicationTests"` 모두 통과.
