# P3-59: 게시판 목록(`board/list.html`)에 "2단 모드" 체크박스 마크업이 없어 관련 JS가 붙잡을
대상이 없음(죽은 스크립트 include)

## 배경

legacy `board/list.scala.html:45`는 `@common.twoColumnModeCheckboxArea(false)`를 호출해
목록을 2단(2-column)으로 볼지 전환하는 체크박스 UI(`#two-column-mode-checkbox`,
`#two-column-mode` 등)를 렌더링한다.

## 현재 yona 상태 (격차 확정)

`src/main/resources/templates/board/list.html`의 `search-wrap` 폼(13~31행)에는 이 체크박스
마크업이 전혀 없다. `grep -n -i "column" board/list.html`의 유일한 매치:

```
144: <script type="text/javascript" src="/javascripts/service/yona.twoColumnMode.js"></script>
```

즉 2단모드 전환 JS(`yona.twoColumnMode.js`)는 로드되지만 그 스크립트가 조작할
`#two-column-mode-checkbox`/`#two-column-mode` DOM 요소 자체가 없다 — 죽은 include다.
`th:replace`/`th:insert`로 다른 프래그먼트에서 끌어오는 경로도 없음을 확인했다.

비교(정상 이식된 6곳): `issue/list.html`, `issue/my_partial_search.html`,
`pullrequest/partial_search.html`(코드 주석으로 "issue/list.html의 #36 마크업을 재사용한다"고
명시), `organization/boardList.html`, `organization/issueSearch_partial.html`,
`user/view.html`은 전부 legacy와 동일한 `two-column-icon`/`two-column-mode-checkbox`/
`two-column-mode` 구조를 갖고 있다 — `board/list.html`만 예외.

`docs/TEMPLATE_BACKLOG.md` #143(`board/list.scala.html` 행)에도 이 누락이 언급돼 있지 않다.

## 제안

- `board/list.html`의 검색 폼 영역에 legacy `board/list.scala.html:45`와 동일한 위치에
  `common/twoColumnModeCheckboxArea` 대응 마크업(다른 6개 화면이 이미 쓰는 것과 동일한
  `#two-column-mode-checkbox`/`two-column-icon` 구조, 초기값 `false`)을 추가한다(다른
  화면들이 이미 인라인 통합해 쓰고 있으므로 그 마크업을 그대로 복사해 legacy 파라미터에
  맞게 조정).
- TDD로 "board/list.html에 two-column-mode-checkbox가 렌더링되고, 클릭 시
  `yona.twoColumnMode.js`가 기대하는 클래스/속성이 토글된다"는 회귀 스펙을 먼저 추가한다.

본 티켓은 순수 조사 산출물이며 구현은 하지 않았다.

## 완료 로그 (2026-09-12)

(2개 케이스)를 먼저 추가해 RED(1/2 실패, 마크업 부재 확인)를 확인한 뒤 구현했다.

- `board/list.html`의 `#option_form` 안(검색창/라벨 필터 다음, legacy 45행과 동일 위치)에
  다른 6개 화면(issue/list.html 등)과 동일한 `#two-column-mode-checkbox`/`#two-column-mode`
  마크업을 추가했다.
- `yobi.board.List.js`가 이미 `_initTwoColumnMode()`(yona.twoColumnMode.js)를 호출하고
  있어(28행) 별도 JS 배선은 불필요했다 — 마크업만 없어서 죽은 include였다는 조사 결론을 그대로
  확인.

**Playwright 실측 검증(1회)**: 기존 dev 서버(재사용)의 GIT 프로젝트 게시판 목록에서 실제
체크박스를 클릭해 `checked` 상태 전환과 `localStorage.useTwoColumnMode` 값 변경까지 확인.
콘솔 에러 0건.

부수 발견(범위 밖, 별도 항목 권장): `issue/list.html`에 "2단 보기"(`#two-column-mode-checkbox`)와
"자식이슈 펼쳐보기"(show-subtasks) 두 서로 다른 위젯이 **동일한 `id="two-column-mode-checkbox"`를

선택하므로 "자식이슈 펼쳐보기" 쪽 팝오버/클릭 동작이 의도대로 안 될 가능성이 있다 — 이 티켓
