## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-47**: 수신메일이 HTML뿐일 때 서식이 손실되던 문제와, 본문 HTML 안의 `cid:xxx` 인라인 이미지가 깨진 채로 남던 문제를 모두 해결. yona `CreationViaEmail.postprocessForHTML`/`replaceCidWithAttachments`를 이식하기 전, 백로그가 명시한 선행 확인(raw HTML을 Issue/Posting 본문에 그대로 저장해도 안전한지)부터 검증 — `MarkdownServiceImpl.render()`가 항상 OWASP `owasp-java-html-sanitizer`([[tickets/p0-08|P0-08]])로 최종 sanitize를 거친 뒤 반환하는 것을 확인했고, 이는 저장 시점 출처(사용자 입력이든 메일이든)와 무관하게 렌더링 시점에 균일하게 적용되므로 raw HTML을 그대로 저장해도 안전하다고 결론.
  - `ImapMailboxPoller`: `extractTextBody`(단순 String 반환, HTML을 jsoup으로 태그 제거)를 `extractBody`(본문+`isHtml` 플래그를 함께 반환)로 교체 — text/plain이 있으면 그걸 쓰고, text/html뿐이면 이제 태그를 벗기지 않고 원본 HTML을 그대로 보존한다. `extractAttachments`가 각 첨부파일의 `Content-ID` 헤더도 함께 추출하도록 확장.
  - `InboundEmailMessage`/`InboundAttachment`: `isHtml: Boolean`, `contentId: String?` 필드를 각각 추가(기존 필드는 하위 호환을 위해 그대로 유지 — `textBody`라는 이름은 유지하되 HTML일 때는 원본 HTML을 담는 것으로 의미를 확장).
  - `IncomingMailProcessingService`: 첨부파일 저장(`attachAttachments`, [[tickets/p1-29|P1-29]])이 이제 `cid → Attachment` 매핑을 반환하도록 확장. 이슈/댓글 생성 직후(이미 본문이 저장된 뒤) `message.isHtml && cid 매핑이 비어있지 않으면` `postprocessHtmlBody`를 호출 — legacy와 동일하게 "먼저 저장 → 첨부파일 저장 → HTML 후처리로 재저장" 순서를 그대로 따른다. `replaceCidWithAttachments`(Jsoup 기반, `src`/`href` 속성 중 `cid:`로 시작하는 것만 실제 저장된 첨부파일의 `/files/{id}` URL로 치환)는 legacy 알고리즘을 그대로 포팅했고, 치환된 것이 하나도 없으면 불필요한 재저장을 피하도록 `null`을 반환해 스킵한다. 이슈 본문은 `IssueRepository`로, 스레드 댓글(`IssueCommentRepository`/`PostingCommentRepository`)은 각각의 리포지토리로 직접 갱신 — 이벤트 발행이 있는 `issueService.updateIssue()` 등을 거치지 않고 legacy의 `comment.update()`/직접 저장과 동일하게 조용히 후처리만 한다.
  - **범위에서 제외한 부분**: legacy의 `HtmlCompressor`(태그 사이 개행 제거로 마크다운 렌더링 시 불필요한 줄바꿈 방지)는 순수 포맷팅 개선이라 이번 패스에서는 다루지 않음 — 기능적으로 서식/링크/인라인 이미지가 보존되는 핵심 요구사항은 충족.
  - 테스트: `ImapMailboxPollerSpec.kt` +2 tests(HTML 원본 보존+isHtml 플래그/인라인 이미지 Content-ID 추출), `IncomingMailProcessingServiceSpec.kt` +2 tests(cid 치환 후 이슈 본문 갱신/매칭되는 첨부파일 없으면 갱신 안 함). 인접 회귀: `domain/mail/*`, `YonaApplicationTests` 전체 재실행 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `./gradlew test --tests "com.github.yonaprojects.yona.domain.mail.*" --tests "com.github.yonaprojects.yona.YonaApplicationTests"` 모두 통과.
