- **2026-08-20 — P1-79**: 리뷰 스레드 상태변경 시 알림 발행 실패가 상태변경 자체를 롤백시키던 문제 수정.
  - `CodeReviewServiceImpl.updateThreadState()`에서 `publishThreadStateChangedNotification()` 호출을 try/catch로 감싸 실패를 흡수(`logger.warn`만 남김) — yona `CommentThreadApp.java:66-70`의 명시적 try/catch(알림 실패해도 상태변경은 항상 커밋)를 그대로 재현. 클래스 레벨 `@Transactional` 하에서 이 호출이 예외를 던지면 메서드 밖으로 전파돼 방금 저장한 상태변경까지 함께 롤백되므로, 여기서 반드시 잡아야 한다.
  - 테스트: `CodeReviewServiceSpec.kt` +1 — `NotificationEventRecorder`를 던지는 목으로 교체한 별도 `CodeReviewServiceImpl` 인스턴스(다른 의존성은 전부 실제 Spring 빈)로 `updateThreadState()`를 호출해, 예외가 전파되지 않고 반환값·DB에 저장된 값 모두 새 상태로 커밋됨을 직접 검증.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `CodeReviewServiceSpec` 26 tests 전체 통과.
