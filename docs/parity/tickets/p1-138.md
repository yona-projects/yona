## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-21 — P1-138**: `StatisticsViewController.statistics()`가 프로젝트 스코프 확인 전에 `loginUser == null`이면 무조건 403을 반환하던 것을 제거.
  - yona `StatisticsApp.java:30`은 `@AnonymousCheck`를 `requiresLogin` 인자 없이(기본값 false) 붙이는데, `AnonymousCheckAction.call()`(`app/actions/AnonymousCheckAction.java:46`)의 실제 차단 조건은 `AccessControl.isAnonymousNotAllowed() || configuration.requiresLogin()` — 즉 사이트 전역 "로그인 강제" 설정이 켜져 있거나 어노테이션에 명시적으로 `requiresLogin=true`를 준 경우에만 익명을 막는다. `StatisticsApp`은 둘 다 아니므로 실제로는 익명 접근이 허용되고, 이후 `@With(DefaultProjectCheckAction.class)`(프로젝트 스코프 확인)가 PUBLIC이 아닌 프로젝트에서만 접근을 막는다.
  - `project.projectScope != ProjectScope.PUBLIC`일 때만 로그인+멤버십을 확인하도록 순서를 바꾸고, `loginUser == null` 케이스도 이 안에서 처리(비공개 프로젝트+익명이면 403).
  - 테스트: `StatisticsViewControllerSpec.kt` 기존 "익명이면 403" 테스트를 "공개 프로젝트는 익명도 200 OK" + "비공개 프로젝트는 익명이면 403" 2건으로 교체. 전체 통과.
