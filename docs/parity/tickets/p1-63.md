## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-63**: PR 리뷰어 참여/취소 알림 제목을 yona `NotificationEvent.afterReviewed()`의 `formatReplyTitle()` 포맷으로 수정.
  - `PullRequestServiceImpl`에 `formatReplyTitle(pullRequest)`(`"Re: [${project.name}] ${title} (#${number})"`, yona `formatReplyTitle(PullRequest)`와 동일 포맷) 신규 private 함수 추가, `notifyReviewerChanged()`의 `title` 계산을 이 함수로 교체 — 기존엔 `newValue`(DONE/CANCEL)에 따라 "...에 리뷰어로 참여했습니다."/"...의 리뷰어 참여를 취소했습니다."로 갈리던 임의의 문장이었으나, yona처럼 참여/취소 여부와 무관하게 항상 동일한 범용 포맷을 쓰도록 단순화(이제 안 쓰이는 `actionLabel` 지역변수도 함께 제거).
  - [[tickets/p1-62|P1-62]] 통합으로 `notifyReviewerChanged()`가 리뷰어 추가/제거 알림의 유일한 발행 지점이라 한 곳만 고치면 두 경로(`PullRequestController`/`ReviewApiController`) 모두에 반영됨을 확인.
  - TDD: 기존 `PullRequestServiceSpec.kt`의 "리뷰어 추가/해제 시 NotificationEvent와 PullRequestEvent가 발행되어야 한다([[tickets/p1-49|P1-49]])" 테스트에 `title shouldBe "Re: [${toProject.name}] ${pr.title} (#${pr.number})"` 단언을 먼저 추가해 레드(`"...#null에 리뷰어로 참여했습니다."`가 나와 실패) 확인 후 구현, 그린 전환 확인.
  - 검증: `./gradlew compileKotlin compileTestKotlin` 전체 컴파일 성공, `./gradlew test --tests "com.github.yonaprojects.yona.domain.pullrequest.PullRequestServiceSpec" --tests "com.github.yonaprojects.yona.domain.pullrequest.CodeReviewServiceSpec"` 43 tests 전체 통과(제목 텍스트를 단언하는 다른 테스트 없음을 전체 검색으로 확인 — 회귀 없음).
