## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-64**: SVN/Git 저장소 접근 권한 필터에 조직 그룹멤버 우회(`AccessControl.isAllowedIfGroupMember`)를 이식.
  - `SvnAuthorizationFilter.isMember()`/`GitAuthorizationFilter.isMember()` 둘 다 동일하게 수정: 기존엔 `projectService.isMember(projectId, loginId)`(직접 멤버 여부)만 확인했는데, 이게 false면 `userRepository.findByLoginId(loginId)`로 사용자를 조회해 `AccessControl.isAllowedIfGroupMember(project, user)`를 추가로 확인하도록 OR 조건 추가. `isAllowedIfGroupMember`가 이미 PUBLIC/PROTECTED에 한해서만 적용되도록(PRIVATE는 그룹멤버여도 배제) 구현돼 있어([[tickets/p1-57|P1-57]]) 별도 분기 없이 그대로 재사용.
  - 테스트: `SvnAuthorizationFilterSpec.kt`/`GitAuthorizationFilterSpec.kt` 각 +2(PROTECTED 프로젝트에서 직접 멤버가 아닌 조직 그룹멤버는 통과/PRIVATE 프로젝트는 조직 그룹멤버라도 여전히 403) — 기존 "멤버가 아닌 유저는 403" 테스트들은 `isMember()`가 이제 `userRepository.findByLoginId()`도 호출하므로 스텁을 추가해 그대로 유지(회귀 없음 확인). 총 13+13 tests 모두 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin` 전체 컴파일 성공, `./gradlew test --tests "com.github.yonaprojects.yona.config.svn.SvnAuthorizationFilterSpec" --tests "com.github.yonaprojects.yona.config.git.GitAuthorizationFilterSpec"` 전체 통과.
