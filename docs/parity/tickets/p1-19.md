- **상태(원본 체크박스)**: `[x]`

- **yona 대상**: `web/BoardViewController.kt`, `domain/comment/CommentServiceImpl.kt`, `domain/board/PostingRepository.kt`
- **비고(원문)**: **완료** — 표기 정정(2026-08-20): 댓글수 갱신은 `PostingServiceImpl.kt`가 아니라 `CommentServiceImpl.kt`(`numOfComments = countByPostingId(...)`)에, 라벨필터는 `PostingRepository.kt`(`findByProjectAndLabelIdsIn`)에 있음. 편집이력은 [[tickets/p2-02|P2-02]]에서 완료(아래 참고)

## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P1-19**: 게시판 목록/댓글 관련 3가지가 yona 대비 저하돼 있던 문제 중 2가지(댓글수, 라벨필터)를 수정. 편집이력(diff)은 별도 이슈([[tickets/p2-02|P2-02]])로 통합했다.
  - **댓글수(numOfComments)**: `Posting.numOfComments` 필드는 있었지만 어디서도 갱신되지 않아 항상 0으로 고정돼 있던 문제(yona `AbstractPosting.save()/update()`의 `numOfComments = computeNumOfComments()` 대응). `CommentServiceImpl.createPostingComment()`/`deletePostingComment()`에서 댓글 저장/삭제 직후 `postingCommentRepository.countByPostingId()`로 재계산해 `Posting`에 반영하도록 추가. `PostingCommentRepository`에 `countByPostingId` 신규 메서드.
  - **라벨필터**: 게시판 목록(`BoardViewController.listPosts`)이 텍스트 검색(`filter`)만 지원하고 라벨 필터는 아예 없던 문제(yona `BoardApp.SearchCondition.asExpressionList()`의 `labelIdSet` 대응). `labelIds` 쿼리 파라미터를 추가하고, `PostingRepository`에 `findByProjectAndLabelIdsIn`(라벨 필터 + 선택적 텍스트 검색을 AND로 결합, yona와 동일한 조합 규칙) 신규 쿼리 추가.
  - **[[tickets/p2-02|P2-02]]에 통합**: 편집이력(`AbstractPosting.history`, `AbstractPostingApp.addToHistory()`)은 yona `utils/diff_match_patch.java`(Google diff-match-patch 포팅본, 워드단위 diff 알고리즘)에 의존하는데, 이 라이브러리 자체가 당시 yona에 없었다. 이미 같은 의존성 문제로 대기 중이던 [[tickets/p2-02|P2-02]]("DiffUtil 워드단위 diff 하이라이팅 없음")와 사실상 동일한 선행 작업이 필요해 새 항목을 만드는 대신 [[tickets/p2-02|P2-02]] 비고에 편집이력도 함께 묶어뒀고, [[tickets/p2-02|P2-02]]가 완료되며 `HistoryUtil.appendHistory()`가 `PostingServiceImpl.updatePosting()`/`IssueServiceImpl.updateIssue()`에 실제로 배선돼 `history` 필드가 채워지는 것까지 완료됨(`[x]`, 아래 [[tickets/p2-02|P2-02]] 완료 로그 참고).
  - 테스트: `CommentServiceSpec.kt` +1(게시글 댓글 작성/삭제 시 `numOfComments` 정합성 확인). `BoardViewControllerSpec.kt` +1(`labelIds` 파라미터 시 라벨 필터 쿼리 사용, 기본 쿼리는 호출되지 않음 확인). 전체 board/comment 도메인 테스트 + `YonaApplicationTests` 재실행으로 회귀 없음 확인.
  - 검증: `./gradlew test --tests "com.github.yonaprojects.yona.domain.board.*" --tests "com.github.yonaprojects.yona.domain.comment.*" --tests "BoardControllerSpec" --tests "CommentControllerSpec" --tests "YonaApplicationTests"` 전체 통과, `./gradlew compileKotlin compileTestKotlin` 전체 컴파일 성공.
