# P3-41: README/이슈 템플릿 편집 진입점에서 제목이 항상 빈칸으로 시작해 매번 재입력해야 함

## 배경

사용자가 `postform?readme=true` 화면에서 "제목을 입력 안 하면 저장이 안 되는데 기본적으로
비어있고, 입력하고 저장해도 다시 편집하면 사라져 있다"고 신고했다.

조사 결과 프로젝트 홈 화면의 "README 만들기"/"편집" 버튼이 **둘 다** 항상 이 create 폼
(`postform?readme=true`)으로 연결되고, 이 화면은 기존에 저장된 게시글의 실제 제목을 전혀
조회하지 않는다는 것을 v1.6 원본(`partial_readme.scala.html`)과 대조해 확인했다 — **이 구조
자체는 v1.6과 동일**하다(회귀 아님). 차이는 v1.6의 `create.scala.html`이 `readme`/
`issueTemplate` 쿼리 파라미터가 있으면 title 필드를 고정 문자열(`"Update README.md"` /
`"ISSUE_TEMPLATE.md: Project Issue Template"`)로 미리 채워둬 사용자가 매번 다시 입력할
필요가 없게 했는데, 이 프리필이 yona 포팅에서 빠져 있었다는 것이다. yona는 제목 없이는
저장이 막히는 필수 검증까지 있어(v1.6과 동일한 클라이언트 검증), 매번 수동으로 타이핑해야
하는 더 나쁜 UX가 됐다.

## 범위

`BoardViewController.createPostForm()`에 `preparedPostBody`와 동일한 조건 분기로
`preparedTitle`을 계산해 모델에 추가(readme→"Update README.md",
issueTemplate→"ISSUE_TEMPLATE.md: Project Issue Template", 그 외→""),
`board/create.html`의 title `<input>`에 `th:value="${preparedTitle}"` 반영.

## 완료 로그

### 2026-09-09 — 발견·수정·검증 완료

**발견**: 실제 서버로 재현(curl로 create/edit 양쪽 저장 경로 모두 정상 영속되는 것을 먼저
확인해 "저장이 안 되는 버그"가 아님을 배제) → 프로젝트 홈 템플릿에서 "만들기"/"편집" 버튼이
둘 다 create 폼으로 감을 확인 → v1.6 원본 `board/create.scala.html`의 `titleMessage` 로직
(readme/issueTemplate 쿼리파라미터 존재 여부로 고정 문자열 프리필) 발견 → yona
`board/create.html`엔 그 프리필이 없음을 확인.

**수정**: 컨트롤러에 `preparedTitle` 계산/모델 추가, 템플릿에 `th:value` 반영(위 범위 그대로).

**테스트**: `BoardViewControllerSpec.kt`에 readme/issueTemplate 각각의 `preparedTitle` 값
검증 테스트 2건 + 기본(둘 다 없음) 시 빈 문자열 검증 1건 추가 — 총 87건 전부 GREEN.

**실사용 검증**: 사용자가 신고했던 바로 그 URL(`.../postform?readme=true`)을 재호출해
`value="Update README.md"`로 채워짐을 확인.

## 완료 기준

- [x] `?issueTemplate=true`로 열면 제목이 "ISSUE_TEMPLATE.md: Project Issue Template"로 미리 채워짐.
- [x] 둘 다 아니면 기존과 동일하게 빈 문자열(회귀 없음).
