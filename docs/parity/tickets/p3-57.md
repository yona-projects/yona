# P3-57: 이슈 상세/이슈 목록 화면에 키보드 단축키 안내(keymap) 도움말이 빠져 있거나
리팩터 이전 방식(하드코딩 복제)으로 남아있음

## 배경

`docs/TEMPLATE_BACKLOG.md` #236(`help/keymap.scala.html`)의 비고는 TASK-0249에서
"파라미터(`section`,`project`)를 못 받는 `th:replace` 전체 include 방식이었던 것을
`th:fragment=\"keymap(section, project)\"`로 교체(board/list.html, board/view.html 두
호출부도 함께 수정)"라고 기록한다 — 즉 이 리팩터링 작업이 **board 쪽 2곳만** 고쳤다고
명시적으로 밝히고 있다.

그런데 legacy `@help.keymap(...)` 실제 호출부는 4곳이다:

- `legacy-yona/app/views/issue/view.scala.html:455` — `@help.keymap("issueDetail", project)`
- `legacy-yona/app/views/issue/partial_list_wrap.scala.html:67,95` — `@help.keymap("issueList", project)`(빈 목록/일반 목록 두 분기)
- `legacy-yona/app/views/board/view.scala.html` — `@help.keymap("boardDetail", project)`
- `legacy-yona/app/views/board/list.scala.html` — `@help.keymap("boardList", project)`

## 확인된 격차

1. **`issue/view.html`에 키맵 도움말이 통째로 없음** — yona
   `src/main/resources/templates/issue/view.html`에서 keymap 관련 마크업/호출을 grep한 결과
   0건. 이슈 상세 화면에서 `?` 등으로 열리는 "키보드 단축키" 도움말 모달 자체가 빠져 있다.
2. **`issue/list.html`은 파라미터화된 fragment를 안 쓰고 옛날 방식 그대로 하드코딩 복제돼
   있음** — `issue/partial_list_wrap.scala.html`이 병합된 `issue/list.html` 376행부터
   `id="helpKeys"` 블록으로 키맵 모달 HTML 전체를 issueList 섹션 전용으로 직접 박아 넣고
   있고(`#{shortcut.issueList}` 등 정적 문자열 하드코딩), TASK-0249가 만든
   `help/keymap :: keymap(section, project)` fragment를 전혀 재사용하지 않는다. TASK-0249가
   "th:replace 전체 include 방식이었던 것을 th:fragment로 교체"라고 한 리팩터링 이전으로
   보이는 상태다.

비교 기준(정상 사례): `board/view.html:191`은
`th:replace="~{help/keymap :: keymap('boardDetail', ${project})}"`, `board/list.html:135`는
`th:replace="~{help/keymap :: keymap('boardList', ${project})}"`로 정확히 파라미터화된
fragment를 쓴다 — TASK-0249 기록대로 board 2곳은 정상.

## 제안

- `issue/view.html`에 `th:replace="~{help/keymap :: keymap('issueDetail', ${project})}"`를
  legacy와 동일한 위치(455행 대응 지점)에 추가한다.
- `issue/list.html`의 하드코딩된 `#helpKeys` 블록을
  `th:replace="~{help/keymap :: keymap('issueList', ${project})}"` 호출로 교체하고, 중복
  하드코딩 마크업은 제거한다(단, 빈 목록/일반 목록 두 분기에서 각각 호출해야 하는지 legacy
  67/95행 조건을 다시 확인할 것 — 단순 통합 가능일 수도 있음).
- 착수 전 `help/keymap.html` fragment가 실제로 `section` 파라미터별로 다른 단축키 목록을
  올바르게 렌더링하는지(`shortcut.issueDetail`/`shortcut.issueList` 메시지 키가 다 있는지)
  먼저 확인한다.
- TDD로 "이슈 상세/이슈 목록에 키맵 fragment가 렌더링된다"는 회귀 스펙을 먼저 추가한다.

본 티켓은 순수 조사 산출물이며 구현은 하지 않았다.
