# P3-64: "맨 위로 스크롤" 버튼(jQuery elevator)이 이슈/게시글 상세 화면에 없음

## 배경

`lib/elevator`(jQuery elevator 플러그인)는 legacy v1.6.1에는 존재하지 않았다(파일 자체가
`git ls-tree v1.6.1`에서 0건) — legacy 커밋 `cd2bf548b`(2018-06-11, "lib: Add page scroll lib,
elevator.js")로 나중에 추가된 기능이다. 최신 legacy(HEAD)의 `app/views/board/view.scala.html`
(208·211·294행)과 `app/views/issue/view.scala.html`(487·491행)에서 지금도 로드·사용 중이다:

```scala
// legacy-yona/app/views/board/view.scala.html
<link ... href="@routes.Assets.at("javascripts/lib/elevator/jquery.elevator.css")">
<script ... src="@routes.Assets.at("javascripts/lib/elevator/jquery.elevator.js")"></script>
...
$.elevator({ shape: 'rounded', glass: true });
```

이 플러그인은 마크업을 요구하지 않고 스스로 화면 우하단에 "맨 위로 스크롤" 버튼(둥근 모양,
유리 효과)을 주입한다.

## 현재 yona 상태 (격차 확정)

`lib/elevator/` 디렉토리는 yona 저장소에도 그대로 vendoring돼 있지만(파일 존재), 어떤
템플릿에서도 `<link>`/`<script>`로 로드하지 않는다(grep 재확인 완료). yona의
`board/view.html`/`issue/view.html`에는 이에 대응하는 스크롤-맨위로 버튼이나 동등 기능이
전혀 없다(grep 결과 관련 마크업/스크립트 0건).

## 영향도

순수 UX 편의 기능(긴 이슈/게시글 스레드에서 맨 위로 빠르게 돌아가는 버튼)이라 기능 손실이나
데이터 문제는 없다. 우선순위는 낮게 보는 것이 합리적이다.

## 제안

이 티켓은 순수 조사 산출물이며 구현은 하지 않았다(사용자 지시로 백로그 등록만 완료). 착수 시:

1. `board/view.html`/`issue/view.html`(legacy와 동일하게 두 화면 한정)에
   `lib/elevator/jquery.elevator.css`+`jquery.elevator.js`를 로드하고,
   `$.elevator({shape:'rounded', glass:true})`를 그대로 호출한다 — legacy와 완전 동치이므로
   설계 결정 없이 바로 이식 가능한 저위험 작업.
2. Playwright로 "페이지를 충분히 스크롤하면 버튼이 나타나고 클릭하면 맨 위로 스크롤된다"만
   1회 확인하면 충분하다.

## 해결 (2026-09-12)

`board/view.html`/`issue/view.html`에 `lib/elevator/jquery.elevator.css`(`<link>`)와
`jquery.elevator.js`(`<script>`)를 로드하고, 각 화면의 기존 인라인 `$(function(){...})` 블록
안에서 `$.elevator(...)`를 호출했다.

**구현 중 정정된 사실**: 티켓 배경 섹션은 board 파일의 호출 스니펫(`glass: true`)만 인용하고
"두 파일과 완전 동치"라고 서술했는데, 실제로는 `issue/view.scala.html`의 호출부(614행)가
`tooltips: true`(`glass`가 아님 — 커밋 `96d56c403`, 2018-07-06)였다. 처음엔 티켓 서술을 그대로
따라 두 화면 다 `glass: true`로 구현했다가, legacy 원본을 재대조해 `issue/view.html`만
`tooltips: true`로 바로잡았다(`board/view.html`은 `glass: true` 그대로 legacy와 일치).

- 테스트: `src/test/kotlin/com/github/yonaprojects/yona/web/ScrollToTopElevatorTemplateRenderingSpec.kt`
  (신규, RED→GREEN. `issue/view.html` 케이스는 `tooltips: true` 검증으로 정정)
- 변경 파일: `src/main/resources/templates/board/view.html`,
  `src/main/resources/templates/issue/view.html`
- Playwright 실측: 이슈 상세 화면에서 충분히 스크롤 시 우하단에 둥근 유리효과 버튼이 나타나고
  클릭 시 맨 위로 스크롤됨을 확인.
