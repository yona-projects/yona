  - `CommentThreadController.kt`에 `CommentThreadRepository`/`AccessControl` 주입, `open()`/`close()`를 yona와 동일하게 공용 `updateState(id, state, authentication)`로 통합 — 스레드 조회(404) → `thread.project`로 project 확보(404) → `accessControl.isAllowed(user, project, thread, REOPEN/CLOSE)`([[tickets/p1-85|P1-85]] 1b에서 이미 구현된 COMMENT_THREAD 리소스 오버로드 재사용, 매니저/작성자/조직관리자/사이트매니저 우회 및 일반 멤버 규칙 그대로 적용) → 거부 시 403 → 서비스 호출.
