## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

- **2026-08-20 — P2-08**: 웹훅 push JSON payload 필드 4곳(site_admin/overview/절대 URL/timestamp 포맷)을 원본 그대로 이식.
  - `WebhookServiceImpl` 생성자에 `yona.base-url` 설정 주입(`NotificationUrlResolver`가 이미 동일 목적으로 쓰던 값 재사용) + `projectUrl(project)` 헬퍼(`"$baseUrl/${owner}/${name}"`) 신설. `commitNode.url`과 `repositoryNode.html_url` 둘 다 이 헬퍼로 절대 URL을 생성하도록 변경(yona `getBaseUrl()+RouteUtil.getUrl(project)` 대응).
  - `senderNode`에 `site_admin` 필드 추가(`sender.isSiteManager`, yona `buildSenderJSON()` 대응).
  - `repositoryNode`에 `overview` 필드 추가(`project.overview`, yona `buildRepositoryJSON()` 대응).
  - `commitNode.timestamp`를 `Instant.toString()`(ISO-8601) 대신 yona `SimpleDateFormat("yyyy-MM-dd'T'hh:mm:ssZ")`와 동일한 `DateTimeFormatter.ofPattern("yyyy-MM-dd'T'hh:mm:ssZ")`(시스템 기본 타임존)로 포맷 — legacy의 12시간제(`hh`) 표기 관례까지 문자열 형식 그대로 재현.
  - 테스트: `WebhookServiceSpec.kt` +2(4개 필드 전부 legacy와 동일한지 검증/일반 사용자는 `site_admin=false`). 인접 회귀: 기존 9 tests, `WebhookNotificationEventListenerSpec` 12 tests 모두 그대로 통과.
  - 검증: `./gradlew compileKotlin compileTestKotlin`, `WebhookServiceSpec` 11 tests, `WebhookNotificationEventListenerSpec` 12 tests 모두 통과.
