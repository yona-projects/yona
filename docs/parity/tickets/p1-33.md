## 완료 로그 (원문, `PARITY_BACKLOG.md`의 "완료 로그" 섹션에서 이관)

> 이 로그 항목은 P1-33와 [[tickets/p1-34|P1-34]]를 함께 다룬다.

- **2026-08-20 — P1-33 + [[tickets/p1-34|P1-34]]**: `DataBackupServiceImpl`이 복원 시 백업된 PK를 명시적으로 그대로 INSERT하면서도 auto-increment/시퀀스를 재설정하지 않아, 복원 직후 첫 신규 행 저장이 이미 복원된 PK와 충돌할 수 있던 문제 수정. 두 항목이 같은 코드 경로(Postgres 방언 + 시퀀스 재설정)를 다루고 있어 함께 처리했다.
  - **[[tickets/p1-34|P1-34]](Postgres 통합테스트) 먼저 작성**: `DataBackupServicePostgresIntegrationSpec.kt`(신규) — `AbstractIntegrationTest`가 MariaDB 컨테이너에 고정돼 있어 재사용할 수 없으므로, `PostgreSQLContainer` + `@DynamicPropertySource`로 별도의 `@SpringBootTest` 컨텍스트를 새로 구성(스키마는 `test` 프로필의 `ddl-auto: create-drop`로 JPA 엔티티에서 자동 생성 — Postgres에서도 정상 동작함을 이번에 처음 확인). 이 테스트가 실제로 P1-33의 버그를 잡아낸다: 신규 빈 DB에 "PK=1을 이미 점유한" 백업(디저스터 리커버리로 과거 백업을 새 DB에 복원하는 것과 동일한 시나리오)을 `importAll()`로 복원한 뒤, 곧바로 `userRepository.save()`로 신규 유저를 저장 — 수정 전에는 PostgreSQL 시퀀스가 여전히 초기값(1)이라 `nextval()`이 반환한 id=1이 방금 복원된 id=1과 충돌해 `DataIntegrityViolationException`(유니크 제약 위반)이 실제로 발생함을 확인(레드).
  - **P1-33(시퀀스 재설정) 구현**: `importAll()`이 각 테이블 INSERT 직후 `resetAutoIncrement(table, dialect, rows)`를 호출하도록 추가 — 백업된 행들의 `id` 컬럼 최댓값을 계산해, MySQL/MariaDB는 `ALTER TABLE ... AUTO_INCREMENT = max+1`(실측상 이미 자동으로 맞춰지지만 방어적으로 명시 재설정), PostgreSQL은 `pg_get_serial_sequence()`로 실제 시퀀스 이름을 찾은 뒤 `setval(seq, max, true)`로 재설정한다. `id` 컬럼이 없는 조인 테이블 등은 `maxOrNull() == null`이라 자동으로 스킵된다(추가 분기 불필요).
  - 구현 중 실수 하나 발견·수정: `SELECT setval(...)`는 결과 행을 반환하는 함수 호출이라 `jdbcTemplate.update()`(결과 없음을 기대)가 아니라 `queryForObject()`를 써야 했다 — 처음엔 `update()`로 잘못 작성해 "A result was returned when none was expected" 오류가 났고, 이를 고치고 나서야 진짜 그린이 됐다(이 과정 자체가 실제 Postgres로 검증하지 않았다면 못 잡았을 오류라 [[tickets/p1-34|P1-34]]를 먼저 처리한 보람이 있었다).
  - 테스트: `DataBackupServicePostgresIntegrationSpec.kt`(신규, 실제 Testcontainers PostgreSQL) 1 test. 기존 `DataBackupServiceIntegrationSpec.kt`(MariaDB) 2 tests 재실행으로 회귀 없음 확인(MariaDB 경로도 `resetAutoIncrement`를 타지만 기존 동작과 결과가 동일).
  - 검증: `./gradlew test --tests "com.github.yonaprojects.yona.domain.site.*" --tests "SiteApiControllerSpec" --tests "SiteControllerSpec" --tests "YonaApplicationTests"` 전체 통과, `./gradlew compileKotlin compileTestKotlin` 전체 컴파일 성공.
