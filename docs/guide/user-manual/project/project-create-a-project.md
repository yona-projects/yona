# 프로젝트 생성하기

프로젝트를 이용하면 소스 코드와 이슈를 관리하고, 코드 리뷰로 다른 사람과 협업할 수 있다.

## 프로젝트 생성하기

프로젝트를 만들려면 화면 오른쪽 위의 `+` 버튼을 누르고 `Create new project`를 클릭한다.

### 새 프로젝트 만들기

양식을 채운 다음 `Create a project` 버튼을 클릭한다.

#### 저장소 종류 선택

프로젝트를 만들 때 저장소 종류를 선택할 수 있다. Git과 SVN 두 가지를 지원한다.

SVN을 선택하면 `Pull Request` 기능은 쓸 수 없다.

### Git 저장소 가져오기

다른 git 저장소를 가져와서 프로젝트를 만들 수도 있다. `Create new project` 화면의
`Import Git repository` 버튼을 클릭한다.

양식을 채운 다음 `Create a project` 버튼을 클릭한다.
