# 프로젝트 Watch 하기

`Watch`를 사용하면 프로젝트에 변경이 생겼을 때 알림을 받을 수 있다.

프로젝트를 Watch 하려면:

1. Watch 하려는 프로젝트로 이동한다.
1. `Watch` 버튼을 클릭한다.
1. 팝업에서 `Watch` 버튼을 클릭한다.

더 이상 Watch 할 필요가 없으면 `Watching` 버튼을 클릭하고 팝업에서 `Unwatch` 버튼을 클릭한다.

## 알림

알림은 메인 페이지에 표시되고 이메일로도 발송된다. 특정 이벤트가 발생하면 알림을 받을 수
있다. 자세한 내용은 [알림 설정하기](../notification/notification-setting.md) 참고.

### 알림 설정하기

알림을 세부적으로 켜고 끌 수 있다.

1. 화면 위쪽의 아바타를 클릭한다.
1. `Account Settings`를 클릭한다.
1. `Notification Settings` 탭을 클릭한다.
1. 변경하고 싶은 알림 항목을 켜거나 끈다.
