# 프로젝트 Fork 하기

`Fork`는 특정 프로젝트를 복사해서 새 프로젝트를 만드는 기능이다.

다른 사람의 프로젝트에 기여하고 싶거나, 다른 프로젝트를 기반으로 자신만의 프로젝트를 시작하고
싶을 때 `Fork`를 사용한다.

Fork한 프로젝트에서 코드를 작성하거나 수정한 뒤에는 `Pull Request`로 원본 프로젝트에 보낼 수
있다.

1. Fork 하려는 프로젝트로 이동한다.
1. 프로젝트 홈 화면 오른쪽 위의 `Fork` 버튼을 클릭한다.
1. 양식을 채운다.
1. `Fork` 버튼을 클릭한다.
