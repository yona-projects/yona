# Pull Request

`Pull Request`를 사용하면 원본 프로젝트 멤버에게 자신이 변경한 코드를 알리고 리뷰를 요청할 수
있으며, 멤버들과 변경 내용에 대해 토론할 수 있다. 코드 리뷰가 끝나면 코드를 병합할 수 있다.

단, `Pull Request`는 git 저장소를 쓰는 프로젝트에서만 사용할 수 있다.

## Pull Request 만들기

1. 자신의 프로젝트 또는 Fork한 프로젝트에서 코드를 작성하거나 수정한다.
1. 저장소에 코드를 push 한다.
1. 프로젝트로 이동한다.
1. `Pull Request` 메뉴를 클릭한다.
1. `New Pull Request` 버튼을 클릭한다.
1. `from`의 프로젝트와 브랜치를 선택한다 — 수정된 코드가 있는 브랜치다.
1. `to`의 프로젝트와 브랜치를 선택한다 — `from` 브랜치가 병합될 대상 브랜치다.
1. `Send pull request` 버튼을 클릭한다.

## 충돌(Conflicts)

수정한 코드가 원본과 충돌하면 Pull Request 화면에 안내가 표시된다. 안내에 따라 충돌을
해결한다.

충돌이 해결되지 않아도 Pull Request 자체는 만들 수 있다. 다만 병합하려면 충돌을 해결해야
하며, 해결되면 `Accept` 버튼이 활성화된다.

## 코드 리뷰

원본 프로젝트 멤버는 코드를 리뷰할 수 있다. 프로젝트 공개 범위가 public이면 멤버가 아닌
사용자도 리뷰하고 다른 사람의 피드백을 받을 수 있다.

1. 리뷰하려는 Pull Request로 이동한다.
1. `Code Review` 탭을 클릭한다.
1. 리뷰 입력창을 여는 방법은 두 가지다.
   1. 리뷰하려는 코드 부분을 마우스로 드래그한 다음 `Comment` 버튼을 클릭한다.
   1. 리뷰하려는 코드 줄 왼쪽의 `Comment` 버튼을 클릭한다.
1. 리뷰 내용을 작성하고 `Add Comment` 버튼을 클릭한다.

코드를 선택하지 않고도 댓글을 남길 수 있다.

1. 리뷰하려는 Pull Request로 이동한다.
1. `Code Review` 탭을 클릭한다.
1. 화면 아래로 이동하면 댓글 입력창이 보인다.
1. 리뷰 내용을 작성하고 `Add Comment` 버튼을 클릭한다.

## Accept

`Accept`를 사용하면 리뷰가 끝난 코드를 원본 프로젝트 저장소에 병합할 수 있다.

1. `Pull Request` 메뉴에서 요청을 클릭한다.
1. `Accept` 버튼을 클릭한다.
