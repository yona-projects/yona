# 알림 받기 (Watch)

`Watching`을 사용하면 프로젝트에 변경이 생겼을 때 메인 페이지와 이메일로 알림을 받을 수 있다.

## Watch

아래 화면들에서 `Watching` 버튼을 볼 수 있다.

- 프로젝트
- 이슈
- 게시글
- Pull Request
- `Code` 메뉴의 커밋

`Watching`을 쓰려면 권한이 있어야 한다. public 프로젝트는 누구나 Watch할 수 있지만, private
프로젝트는 그 프로젝트 멤버만 Watch할 수 있다.

### 프로젝트 Watch 하기

`Watch Project`를 하면 아래와 같은 상황에서 알림을 받는다.

- 새 이슈
- 새 게시글
- 새 Pull Request
- 이슈 상태 변경
- 이슈 담당자 변경
- Pull Request 상태 변경
- 게시글/이슈에 새 댓글
- Pull Request에 새 댓글
- 프로젝트 가입 요청
- Pull Request 병합
- 커밋에서 이슈 언급
- Pull Request 커밋 변경
- 프로젝트에 새 커밋
- Pull Request 리뷰 상태 변경
- Pull Request에서 이슈 언급
- 이슈 본문 변경
- 리뷰 스레드 상태 변경
- 그룹 가입 요청
- 댓글 수정

프로젝트를 Watch 하려면:

1. 프로젝트로 이동한다.
1. `Watch` 버튼을 클릭한다.
1. 팝업에서 `Watch` 버튼을 클릭한다.

기본적으로는 위의 모든 상황에서 알림을 받는다. 더 세부적으로 설정하고 싶다면
[알림 설정하기](notification-setting.md) 참고.

## Unwatch

더 이상 알림을 받고 싶지 않다면 `Unwatch`를 사용한다.

### 프로젝트 Unwatch 하기

1. Watch 중인 프로젝트로 이동한다.
1. `Watching` 버튼을 클릭한다.
1. 팝업에서 `Unwatch` 버튼을 클릭한다.

### 게시글/이슈/Pull Request Unwatch 하기

개별 항목의 알림을 끄려면:

1. `Board`, `Issues`, `Pull Request`의 항목으로 이동한다.
1. `Unwatch` 버튼을 클릭한다.
