# 프로젝트 삭제하기

프로젝트 관리자 권한이 있으면 `Delete this project` 기능으로 프로젝트를 삭제할 수 있다.

1. 삭제하려는 프로젝트로 이동한다.
1. 톱니바퀴 `Project Settings` 버튼을 클릭한다.
1. `Delete project` 탭을 클릭한다.
1. `I agree to delete this project` 체크박스를 클릭한다.
1. `Delete this project` 버튼을 클릭한다.

한 번 삭제한 프로젝트는 복구할 수 없다.

삭제 시 관련된 이슈/게시글/Pull Request/라벨/웹훅 등이 함께 정리(cascade)된다 — 자세한 배경은
`docs/PARITY_BACKLOG.md`의 P0-19 참고.
