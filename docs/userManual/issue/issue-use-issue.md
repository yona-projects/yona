# Using issues

Many tasks exist when projects are ongoing. For managing and tracing these tasks, yona provides
a solution, `Issues`.

You can share problems and tasks with project members by creating issues and assigning them.
You can also manage schedules using `Milestone`.

Creating new issues
-------------------

1. Go to a project in which you want to make an issue.
1. Click the `New issue` button.
1. Fill out the form and then click the `Save` button.

### Assignee

You can choose an assignee for the issue.

1. Click the `Assignee` drop-down box on the right of the issue page.
1. You'll see the project members.
1. Click a member to assign the issue to.

Assigning an issue to a member means that member should solve the issue.

Issues are filtered by project member names on the `Issues` page.

### Milestones

You can do schedule management by assigning milestones to issues.

See [issue-use-milestone.md](issue-use-milestone.md) for more information.

### Labels

You can label issues for categorizing and searching. One or more labels can be added to an
issue.

See [issue-use-labels.md](issue-use-labels.md) for more information.

Closing issues
--------------

To close an issue:

1. Go to the issue you want to close.
1. Click the `Close issue` button at the bottom of the issue page.

Reopening issues
----------------

To reopen an issue:

1. Go to a closed issue.
1. Click the `Reopen issue` button at the bottom of the issue page.
