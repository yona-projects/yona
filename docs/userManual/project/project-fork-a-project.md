# Forking projects

`Fork` is creating a project by copying a certain project.

If you want to contribute to another user's project or start your own project based on someone
else's, use `Fork`.

After writing or modifying code in a forked project, you can send it to the original project by
using `Pull Request`.

1. Go to the project you want to fork.
1. Click the `Fork` button on the top right of the project home page.
1. Fill out the form.
1. Click the `Fork` button.

On Windows, Fork uses filesystem hard links — see
[README's "Prerequisites for using Fork (hard-link cloning) on Windows"](../../../README.md#prerequisites-for-using-fork-hard-link-cloning-on-windows)
for the constraints.
