# Deleting projects

To delete a project, use the 'Delete this project' function, provided you have administrator
authorization.

* Go to the project you want to delete.
* Click the gear-shaped `Project Settings` button.
* Click the `Delete project` tab.
* Click the 'I agree to delete this project' checkbox.
* Click the `Delete this project` button.

Once you delete a project, you can't recover it.

Deletion cascades to related issues/posts/pull requests/labels/webhooks etc. — see
`docs/PARITY_BACKLOG.md` P0-19 for background.
