# Yona MCP 통합 가이드 문서 설계

## 목적

Yona 관리자와 MCP 클라이언트 사용자가 한 문서만으로 서버를 활성화하고,
사용자 토큰을 발급해 연결한 뒤 읽기 전용 기능을 점검할 수 있게 한다.

## 문서 위치

- 통합 가이드: `docs/ko/yona-mcp-guide.md`
- 기존 기술 문서: `docs/technical/mcp-server.md`

기존 기술 문서는 프로토콜 요약으로 유지하고 통합 가이드 링크를 추가한다.

## 구성

1. MCP 개요와 읽기 전용 범위
2. 서버 활성화와 `mcp.allowedOrigins` 설정
3. 사용자 토큰 발급과 보관
4. MCP 엔드포인트와 인증 방식
5. 주요 MCP 클라이언트 연결 예시
6. 도구, 리소스, 프롬프트 목록과 사용 예시
7. `curl` 기반 연결 점검
8. 권한, 보안, 오류 해결
9. 현재 제한 사항

## 작성 원칙

- 문장과 절을 짧게 유지한다.
- 설정 후 바로 검증할 수 있는 순서로 설명한다.
- 토큰은 환경변수로 전달하고 예제에 실제 값을 넣지 않는다.
- 구현된 기능만 설명한다.
- 쓰기 기능과 실시간 SSE 전송은 지원하지 않는다고 명시한다.
- 프로젝트 접근 결과는 웹 UI와 같은 사용자 권한을 따른다고 설명한다.
- 도구 인자, 제한값, 리소스 URI는 현재 코드와 일치시킨다.

## 완료 기준

- 관리자가 MCP 서버를 활성화하고 Origin 정책을 설정할 수 있다.
- 사용자가 Yona UI에서 토큰을 발급하고 클라이언트를 연결할 수 있다.
- 제공 도구 8개, 리소스 5종, 프롬프트 3개의 용도를 확인할 수 있다.
- 인증, 권한, 잘못된 요청, 비활성화 상태를 스스로 진단할 수 있다.
- 기존 기술 문서에서 통합 가이드로 이동할 수 있다.
