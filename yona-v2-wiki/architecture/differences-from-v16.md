

- **비밀번호 정책(NIST SP 800-63B)**: 새 비밀번호는 8자 이상 128자 이하이고, 대문자, 숫자, 기호 같은 구성은 강제하지 않는다. 흔한 비밀번호와 같은 글자 반복, 아이디나 이메일과 같은 값은 거절한다(400). 가입, 비밀번호 변경, 재설정, 최초 관리자 설정에 적용된다. v1.6은 서버에서 아무 검사도 하지 않아 한 글자도 받았다. 이미 저장된 비밀번호는 그대로 둔다.
- **Mercurial의 기본으로 설정**: v1.6에서 옮긴 단추가 Mercurial에서 아무 일도 하지 않았다. 지금은 선택한 북마크의 이름을 저장소 안 `.hg/yona-default-branch`에 기억해 Yona 화면과 풀 리퀘스트의 기본 브랜치로 삼는다(`@` 북마크는 리비전에 고정되어 쓰지 않았다). `hg clone`의 체크아웃은 Mercurial의 규칙을 따른다(A-467).
- 프로젝트 삭제 확인 창은 `owner/name`을 다시 입력해야 "예"가 켜진다(A-536, 선생님 승인 추가). 서버 요청 계약은 v1.6 그대로이다.
- 이슈 템플릿(`ISSUE_TEMPLATE.md`)은 프로젝트 관리자(여러 명 가능)와 사이트 관리자만 바꿀 수 있다. Git 푸시, 온라인 편집, 설정 화면의 편집 단추에 적용했고 조직 프로젝트의 조직 관리자도 포함한다. v1.6에는 제한이 없었다(A-565, R-167). 풀 리퀘스트 병합, 코드 화면의 경로 편집, Mercurial 푸시는 아직 적용하지 않았다.
- 변경된 내용을 보여 주는 화면(Git 커밋, 비교, 코드 주고받기 변경 내용, Subversion 커밋과 비교)에서 변경 파일이 둘 이상이면 diff 왼쪽에 변경 파일 트리를 보이고, 파일을 고르면 그 파일의 diff만 보인다. 서버 계약은 v1.6 그대로이다(A-571, 선생님 지시 추가).
