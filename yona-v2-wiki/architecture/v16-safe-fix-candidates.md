# 정상 흐름을 바꾸지 않는 결함 수정 후보

[v16-retained-defects.md](v16-retained-defects.md)의 재현 결함 296건을 한 건씩 읽고, **정상 사용 흐름은 바꾸지 않고 오류나 어색한 동작만 바로잡는 것**만 추렸다(2026-11-04, 104건. 괄호의 별칭은 같은 결함의 다른 번호이다). v1.6의 결함이므로 선생님의 승인 없이는 고치지 않는다. 분류는 코드를 읽은 판단이며 고치기 전에 시험으로 확인한다.

**넣은 기준**
- 오류(500, NPE, TypeError)가 나던 입력만 정상 처리로 바꾸는 것. 오류가 없던 입력의 동작은 그대로이다.
- 문구, 메시지 키, 링크, 표시의 오타와 불일치를 고치는 것.
- 화면 스크립트(JS)의 오류와 중복 실행을 고치는 것.

**뺀 기준**: 누가 무엇을 볼 수 있는지 달라지는 것(권한, 노출 범위, 보안 항목 전부), 저장되는 데이터나 내보내기 형식이 달라지는 것, 알림과 이벤트가 새로 생기거나 사라지는 것, 검색과 정렬의 규칙이 달라지는 것, 가입과 로그인 규칙이 달라지는 것(예: R-59-5 로그인 ID 접미사, R-19-1 탈퇴 조건), 설계 판단이 필요한 큰 작업(R-56-2, R-51-2).

## 처리 결과 (2026-11-04)

선생님의 지시("tdd로 처리", "보안은 제외")에 따라 위 104건을 시험 먼저 쓰고 고쳤다. 이후 선생님이 R-58-3(주소를 `https://yona.dev`로), R-15-4와 R-59-12(권장안 수용), R-58-6(읽을 수 없는 첨부만 표시)을 정하셔서 이어서 처리했다. **100건을 고쳤고 4건은 고치지 않았다.** 건별 처리 내용은 선생님께 드린 보고 페이지(아티팩트)에 있다.

**고치지 않은 4건**
- R-54-3: 선생님이 현재 상태 유지로 정하셨다(화면에 보이는 변화가 없는 항목이다).
- R-61-12, R-124-4: 코드를 다시 보니 이미 해결되어 있었다.
- C180(C053, R-38): 폴더 링크에 `#cb-` 앵커를 붙이면 화면 스크립트의 `hashchange` 처리가 해시를 접두어 없이 경로로 읽어 새 탭으로 열 때 없는 경로를 요청한다. 앵커, 스크립트, 줄 id를 함께 고쳐야 하며 권장은 현재 유지이다. 선생님의 결정을 기다린다.

**시험 방식**: Java 쪽은 기존 통합 시험에 시험을 먼저 추가하고(Red 확인) 고쳤다. 화면 스크립트(JS)는 저장소에 JS 시험 도구가 없어 `src/test/js/`에 Playwright(Chromium) 기반 도구를 새로 만들었다(`node src/test/js/run.mjs [이름]`). 실제 JS 파일을 불러 DOM에서 실행하고, 템플릿의 인라인 스크립트는 조각을 잘라 실행한다.
