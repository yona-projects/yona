# 이슈 수정

구현은 `IssueEditController`(폼, 수정), `IssueService.update`(변경, 이동, 이벤트), `IssueHistory`(변경 이력), `diff_match_patch`(v1.6 소스 그대로)이다. 화면은 `issue/edit.html`이다. 테스트는 `IssueEditTest` 17건과 `IssueServiceTest`의 수정 12건이다.

## 폼 (`GET issue/:number/editform`)

이슈를 읽을 수 있으면 열린다(수정 권한이 없으면 저장 단추와 편집 항목이 빠진 "원본 보기" 상태). 없는 이슈는 `404`, 읽을 수 없으면 `403`.

- 머리: 번호(`#N`, 초안은 `Draft` 표시), 제목 입력(250자), 하위 이슈 선택(항상 펼쳐져 있다. 이미 하위 이슈가 있으면 "이미 부모 이슈입니다" 한 항목만), 본문 편집기, 첨부, 단추.
- 단추: 초안이면 `게시`(`#button-draft-publish`, `isPublish=true`), `초안 저장`(`isDraft=true`), 아니면 `저장`. 작성자이고 초안이 아니면 "알림 메일" 체크(`notificationMail`, 기본 선택).
- 오른쪽: 상태 선택(상태 수정 권한), 담당자(담당자 수정 권한), 마일스톤(마일스톤 메뉴가 켜져 있고 마일스톤 수정 권한이 있을 때), 마감일(`yyyy-MM-dd`), 라벨. 세 권한은 모두 이슈 수정 권한을 따른다.
- 숨은 값: `authorId`, `isDraft=false`, `isPublish=false`.

## 수정 (`POST issue/:number/edit`, 멀티파트)

순서: (1) 폼 오류(제목 필수, 255자, 마감일 형식)는 `400`으로 폼을 다시 보여 준다(제목과 본문은 고치기 전의 값). v1.6은 이때 널 포인터로 `500`이었다(A-45). (2) 수정 권한이 없으면 `403`. (3) `targetProjectId`가 있으면 대상 프로젝트를 확인한다(없으면 안내와 `400`, 이슈를 만들 수 없으면 `403`). (4) `body`가 오지 않으면 `413`. (5) 같은 분류의 라벨을 둘 이상 고르면 `400`과 평문 메시지.

값은 폼의 값을 모두 반영한다. 비워 보낸 마감일, 담당자, 라벨은 지워지고, **보내지 않은 마일스톤은 마일스톤 없음**이다(마일스톤 메뉴를 끈 프로젝트에서 고쳐도 마일스톤이 풀린다). `state`를 보내지 않으면 현재 상태를 유지한다.

- **변경 이력**: 본문이 바뀌면 `history`에 "수정한 사람(아이디) + n − n at 시각" 머리와 바뀐 조각(`diff-deleted`, `diff-added`, 같은 부분이 100자를 넘으면 앞뒤 50자만 남기고 `diff-ellipsis`)을 이전 이력 앞에 쌓는다. 줄바꿈은 `</br>`. 본문은 이스케이프한다. 초안 게시는 이력을 비운다.
- **초안 게시**: 새 번호, 지금 시각, 열림 상태. `IssueCreatedActivity`를 발행하고 새 번호의 보기 화면으로 보낸다.
- **부모**: 하위 이슈 선택을 보냈을 때(`targetProjectId` 있음)만 `parentIssueId`로 바꾸고 비어 있으면 푼다.
- **다른 프로젝트로 이동**: 이슈와 하위 이슈가 새 번호를 받고(대상 프로젝트의 다음 번호) 만든/수정 시각을 갱신하며, 마일스톤은 지우고, 댓글의 프로젝트를 바꾸고, 라벨은 수정한 사람이 대상 프로젝트의 구성원이면 같은 분류, 이름으로 옮기고(없으면 만든다) 아니면 지운다. 내 비공개 프로젝트에서 옮기면 이력을 지운다. 이동 이벤트(`ISSUE_MOVED`, 이전 `소유자/이름` → 새 `소유자/이름`)와 `IssueCreatedActivity`를 남긴다(내 비공개 프로젝트에서 옮길 때는 제외).
- **이벤트**: 초안이 아니고 `notificationMail=yes`이거나 수정한 사람이 작성자가 아니면 담당자, 상태, 본문 변경 이벤트를 남긴다. 편집 폼으로는 마일스톤과 라벨 이벤트를 남기지 않는다(일괄 변경에서만).
- 제목 머리말 개수는 이전 프로젝트에서 줄이고 새 프로젝트에서 늘린다(A-46). 멘션 기록은 새 본문에 맞춘다. 임시 첨부는 이슈로 옮긴다.
- 성공하면 `303`으로 보기 화면(옮겼으면 새 위치, 게시했으면 새 번호)으로 보낸다.
