# 화면 영역별 점검 현황

선생님과 함께 화면을 영역별로 보며 다듬는 작업의 진행 상태이다. 영역을 마치면 선생님이 "완료"로 확인하신 날을 적는다. 결정과 변경 내용은 [decisions.md](decisions.md)의 에이전트 판단 표(A-번호)에 있다.

## 완료한 영역

| 영역 | 확인 | 결정 기록 |
|---|---|---|
| 프로젝트(설정 포함) | 2026-11 중순 | A-561 ~ A-566 |
| 이슈 | 2026-11 중순 | A-567 |
| 코드 주고받기 | 2026-11 중순 | A-568 ~ A-569 |
| 코드(파일, diff, 비교, 이력, 빈 저장소, Subversion) | 2026-11 중순 | A-570 ~ A-572 |
| 게시판, 위키, 마일스톤 | 2026-11 중순 | A-573 ~ A-576 |
| 조직(그룹) | 2026-11-14 | A-577 ~ A-580 |
| 사용자(설정, 로그인과 가입, 2단계 인증, 기기 인증, OAuth 승인) | 2026-11-15 | A-581 ~ A-588 |

사용자 영역에서 선생님 결정으로 **그대로 둔 것**: 프로필 수정 화면(개선 시안만 보여 드렸고 적용하지 않았다), 로그인 창과 전체 화면 로그인의 2단계 오류 알림 모양, 알림 화면, 기기 인증 결과 화면.

## 남은 영역(점검 전)

사이트 관리 15개, 검색 8개, 오류 9개(404와 400의 홈 단추는 A-586에서 테마색으로 바꿨다), 첫 화면의 알림 2개, 도움말 2개, 환영 2개, 기타 각 1개.
